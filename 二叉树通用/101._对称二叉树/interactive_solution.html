LeetCode 100. 相同的树
简单
二叉树 深度优先搜索 递归
准备开始：大家好，今天我们来讲解LeetCode第100题"相同的树"。这是一道经典的二叉树递归问题。
步骤1：我们开始比较两棵树的根节点。首先检查基础情况：两个节点是否都为空。
步骤2：接下来检查结构差异：如果一个节点为空而另一个不为空，说明结构不同。
步骤3：现在比较根节点的值。如果值不相等，两棵树就不相同。
步骤4：根节点相同后，我们递归比较左子树。这体现了分治的思想。
步骤5：左子树比较完成。注意这里使用了短路求值的优化。
步骤6：继续递归比较右子树。只有左右子树都相同，整棵树才相同。
步骤7：右子树比较完成。我们可以看到递归的强大之处。
完成：算法执行完毕！时间复杂度O(min(m,n))，空间复杂度O(min(m,n))。这就是递归在树结构中的经典应用。

📋 题目描述

给你两棵二叉树的根节点 p 和 q，编写一个函数来检验这两棵树是否相同。

如果两个树在结构上相同，并且节点具有相同的值，则认为它们是相同的。

🎯 核心要求

  • 结构相同：两棵树的形状必须一致
  • 节点值相同：对应位置的节点值必须相等
  • 完全匹配：所有节点都必须满足上述条件
输入：p = [1,2,3], q = [1,2,3]
输出：true
解释：两棵树结构相同，节点值也相同

💡 解题思路

✅ 递归方法（推荐）

思路：递归比较每个节点

时间：O(min(m,n))

空间：O(min(m,n))

优点：代码简洁，易理解

⚡ 迭代方法

思路：使用栈模拟递归

时间：O(min(m,n))

空间：O(min(m,n))

优点：避免递归栈溢出

🔄 递归方法详细讲解

核心思想：分治法

两棵树相同 ⟺ 根节点相同 且 左子树相同 且 右子树相同

  1. 递归基1：两个节点都为空 → 返回 true
  2. 递归基2：一个为空另一个不为空 → 返回 false
  3. 值比较：两个节点值不相等 → 返回 false
  4. 递归调用：同时递归比较左右子树
  5. 结果合并：使用AND运算符合并左右子树结果
🎯 关键点：利用短路求值，左子树不同时直接返回false

⚡ 迭代方法详细讲解

核心思想：栈模拟递归

使用显式栈来模拟递归调用过程，避免系统递归栈

  1. 初始化：创建栈，将两个根节点压入栈
  2. 循环处理：当栈不为空时继续处理
  3. 弹出节点：从栈中弹出一对节点进行比较
  4. 空节点检查：处理两个节点的空值情况
  5. 值比较：比较两个节点的值
  6. 子节点入栈：将左右子节点对压入栈
  7. 继续循环：重复直到栈为空
💡 优势：避免深度递归导致的栈溢出问题

📊 复杂度分析

时间复杂度：O(min(m,n))

  • m 和 n 分别是两棵树的节点数
  • 最坏情况下需要遍历较小树的所有节点
  • 一旦发现不同就立即返回，具有剪枝效果

空间复杂度：O(min(m,n))

  • 递归调用栈的深度
  • 最坏情况是完全不平衡的树（链状）
  • 最好情况是完全平衡的树：O(log min(m,n))

📚 核心知识点深度解析

🌳 二叉树基础概念

定义：每个节点最多有两个子节点的树结构

  • 根节点：树的顶部节点，没有父节点
  • 叶子节点：没有子节点的节点
  • 内部节点：至少有一个子节点的节点
  • 子树：任意节点及其所有后代组成的树
💡 为什么学习二叉树？
二叉树是最基础的树结构，是理解BST、堆、AVL树等复杂数据结构的基础。

🔄 递归思想核心

核心理念：将大问题分解为相同类型的小问题

🎯 递归三要素：
1. 递归基：最简单的情况，直接返回
2. 递归关系：如何分解问题
3. 状态传递：传递什么参数
🌟 本题递归设计：
• 递归基：两节点都空→true；一空一非空→false
• 递归关系：比较根节点+递归比较左右子树
• 状态传递：传递对应的子树节点

🎯 深度优先搜索(DFS)

核心思想：优先访问更深层节点，无法深入时回溯

📋 三种遍历方式：
• 前序遍历：根 → 左 → 右
• 中序遍历：左 → 根 → 右
• 后序遍历：左 → 右 → 根
✨ 本题使用前序遍历：
1. 先比较根节点（根）
2. 递归比较左子树（左）
3. 递归比较右子树（右）
优势：可以尽早发现不同，提高效率

⚡ 短路求值优化

概念：逻辑运算中的性能优化技巧

🔧 工作原理：
• AND运算(&&)：第一个为false时，不计算第二个
• OR运算(||)：第一个为true时，不计算第二个
💡 本题应用：
return isSameTree(p.left, q.left) && isSameTree(p.right, q.right)
如果左子树不同，直接返回false，不会计算右子树
🚀 性能优势：
• 减少不必要的函数调用
• 提高程序执行效率
• 在树结构中特别有效

❌ 常见误区深度分析

误区1: 忘记处理空节点

错误代码：

if p.val != q.val:  # 没有检查p和q是否为空
    return False

为什么错：当p或q为空时，访问.val会导致空指针异常

正确做法：先检查节点是否为空，再比较值

误区2: 递归终止条件不完整

错误思路：只考虑两个节点都不为空的情况

为什么错：没有处理空树比较、一个为空一个不为空的情况

正确做法：必须考虑所有可能的组合情况

💬 面试官常问问题及标准答案

Q1: 这道题的时间复杂度是多少？为什么？

A: O(min(m,n))，其中m和n是两棵树的节点数。因为我们需要比较每个节点，但一旦发现不同就会立即返回，所以最多访问较小树的所有节点。

Q2: 空间复杂度是多少？

A: O(min(m,n))，这是递归调用栈的深度。最坏情况下（完全不平衡的树），深度等于节点数；最好情况下（完全平衡的树），深度为O(log min(m,n))。

Q3: 能否用迭代方法实现？有什么优缺点？

A: 可以用栈模拟递归。优点是避免递归栈溢出，适合深度很大的树；缺点是代码稍微复杂一些，需要手动管理栈。
