# LeetCode 100. 相同的树 - 交互式学习工具

## 📖 项目介绍

这是一个专为LeetCode第100题"相同的树"设计的交互式学习工具，特别适合录制讲解视频和在线学习。

## 🚀 功能特性

### 🎯 核心功能
- **算法可视化**：直观展示二叉树比较过程
- **步骤控制**：支持逐步演示、自动播放、速度调节
- **多语言支持**：Python、Java、JavaScript代码示例
- **实时代码高亮**：当前执行行高亮显示

### 🎥 录制友好
- **全屏模式**：无干扰的录制环境
- **讲解模式**：更大的字体和元素，适合视频录制
- **快捷键操作**：流畅的演示控制
- **清晰的视觉反馈**：高对比度设计

### 📚 学习辅助
- **多个示例**：包含3个典型测试用例
- **笔记功能**：支持实时记录和本地保存
- **常见错误提示**：避免典型编程陷阱
- **面试技巧**：相关的面试问题和答案

## 🎮 使用方法

### 基本操作
- **下一步**：点击绿色箭头按钮或按空格键/右箭头键
- **上一步**：点击黄色箭头按钮或按左箭头键
- **重置**：点击红色重置按钮或按Ctrl+R
- **自动播放**：点击蓝色播放按钮

### 快捷键
- `空格键` / `→`：下一步
- `←`：上一步
- `Ctrl + F`：切换全屏模式
- `Ctrl + R`：重置演示
- `Ctrl + N`：打开/关闭笔记面板

### 界面说明
1. **顶部导航**：题目信息、难度标签、功能按钮
2. **左侧面板**：题目描述和示例切换
3. **中央区域**：算法可视化和步骤说明
4. **右侧面板**：代码展示和语法高亮
5. **底部控制**：操作按钮和进度控制
6. **笔记面板**：学习笔记和常见错误提示

## 📋 算法说明

### 解题思路
1. **基础情况**：两个节点都为空时返回true
2. **结构检查**：一个为空另一个不为空时返回false
3. **值比较**：两个节点值不相等时返回false
4. **递归比较**：同时比较左右子树

### 复杂度分析
- **时间复杂度**：O(min(m,n))，其中m和n分别是两棵树的节点数
- **空间复杂度**：O(min(m,n))，递归调用栈的深度
