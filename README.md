**LeetCode-Top-150** contains complete, well-organized solutions for the **LeetCode interview Top 150**. Each problem includes descriptions (EN/CN), interactive HTML visualizations, and multi-language solution templates (C, C++, Java, JS, Python, Rust, Go, Swift, Kotlin, TS and more).

> [!NOTE]
> 中文项目：LeetCode 面试经典 150 题完整题解与解析——多语言模板 + 交互可视化。

---

## Quickstart

```bash
git clone https://github.com/Windyhhh/LeetCode-Top-150.git
cd LeetCode-Top-150

# Browse problems by topic folder
ls 二叉树通用/
# open a problem's interactive_solution.html in the browser
```

Each problem folder contains `problem_info.json`, `problem_description_en.md` and a `code_templates/` directory with solutions in many languages.

## Features

- **Top 150 coverage** — the classic interview set.
- **Multi-language templates** — 15+ languages per problem.
- **Interactive visualizations** — `interactive_solution.html` per problem.
